库存记录本 —— 使用说明
====================

【怎么打开】
双击「库存记录本.exe」即可使用（第一次打开如出现蓝色提示"已保护你的电脑"，
点「更多信息」→「仍要运行」即可，这是正常现象）。
也可以双击「创建桌面快捷方式.bat」，以后从桌面图标打开。

【第一次使用】
1. 打开软件后，先点顶部「产品与客户」页。
2. 点「新增客户」，把客户加进去（类型选 批发/VIP/零售，
   类型决定下单时自动用哪档价格）。
3. 点「新增产品」，填品名（比如"螺丝"），保存后会自动弹出「新增规格」窗口，
   填规格名（比如 M6×30）、批发价/VIP价/零售价（至少填一档）、初始库存。
   新建页显示的是「规格」：产品加了规格，才会出现在新建页；
   还没加规格的产品会在新建页顶部提示，随时可以补加。
4. 回到「新建」页就可以开始新建了。

【改产品 / 纠错（产品与客户页）】
- 「产品与规格」和「客户」列表上方都有搜索框：
  输入品名或规格名的一部分（比如"螺丝"或"M6"），
  列表会立刻过滤出匹配的产品/规格，不用一直往下翻。
- 找到后点「编辑」改名称/价格，点「纠错」直接改库存数字。

【怎么新建】
1. 先选客户：客户框里可以直接打字搜索（输入名字的一部分，比如"王"），
   从下拉列表点选即可；选好后再填订单号（自己编一个号，每个订单号只能用一次）。
2. 在左边找到要卖的产品规格，点 +/− 调数量，点「加入订单」。
3. 右侧订单栏会自动算出总价，点「下单」确认，屏幕上显示的总价就是报给客户的钱。
4. 点「确认成交」后，库存自动扣减，已售数自动累加。
   - 库存可以卖成负数：比如货已经到了、但还没来得及录入系统时，
     照常下单就行，下单确认时会用红字提醒哪些规格会变成负数；
     之后用「补货」把库存补上即可。
   - 数量可以填一位小数（比如 1.2 件、库存 100.2），最少 0.1、最多保留一位小数；
     多于一位小数（如 1.25）会提示填写错误。
     修改订单、OCR 识别、补货里的数量同样最少 0.1。
5. 价格档说明：「自动」=按客户类型用对应档（批发客户用批发价）。
   如果这一单想临时换档，点「批发/VIP/零售」按钮即可；
   某个规格没设这档价时，会自动按零售价算。
   软件里所有价格都按 批发价 → VIP价 → 零售价 的顺序显示。

【批量下单（表格导入）】
1. 新建页点订单栏里的「批量下单（表格导入）」→「① 下载批量下单模板」，
   得到一个 Excel 模板，两列：订单号 | 订单明细。
2. 一行一笔订单：「订单号」填订单号，「订单明细」每行写一条
   「规格名=数量」（如 AA3=10），多条明细在同一个格子里换行写。
   只写规格名（不用写产品名），软件会自动匹配对应的产品；
   规格名要和软件里完全一致、所有产品里的规格名不要重复。
   数量最少 0.1、最多一位小数。
   （以前那种「产品名规格名=数量」的旧写法也还能导入。）
3. 回到软件点「② 选择填好的表格导入」：
   - 预览里先选客户（价格按客户类型自动算，和手动下单一样）；
   - 对不上的行（产品/规格名字不对、数量不对、订单号为空）会列出来并跳过；
   - 点「确认导入」，第一笔订单就进入右侧订单栏，订单号自动填好。
4. 像平时一样点「下单」→「确认成交」；成交后会自动载入下一笔订单，
   依次处理完即可，最后一笔成交后会提示全部完成。
5. 注意：表格里订单号如果和以前用过的重复，预览里会标 ⚠，
   下单时会提示换一个号。
6. 以前那种 4 列表格（订单号 | 产品名 | 规格名 | 数量）也还能导入。

【订单管理】
- 点顶部「订单管理」能看到所有订单，可以查看、修改、删除。
- 上方的搜索框可以搜订单号、客户名、品名、规格名（比如搜 vp10，
  就能列出所有含 vp10 的订单），配合日期筛选一起用。

- 每笔订单显示状态：未完成 = 还没开账单；已完成 = 已从账单管理导出过账单。
  （点「查看」可以手动切换状态，导错账单时改回「未完成」即可。）
- 每笔订单还有「付款状态」：已付款（绿）/ 未付款（红），和账单状态互不影响。
  列表每行有「标记已付款」按钮，点开订单详情里也有；点错了再点一次
  「改回未付款」即可。新订单默认都是未付款。
- 一键收款：先按日期/搜索筛选，再点表头勾选框全选（或一个个勾），
  点「一键收款（勾选）」，勾中的订单全部变成已付款；
  点错了可以单笔「改回未付款」。
- 修改订单：改数量、加/删产品、换客户、改订单号都可以，库存会自动跟着变。
- 删除订单：卖出去的东西会自动退回库存。
- 「导出订单表格」导出全部（或筛选后的）订单，Excel 能打开，
  表格最后一行会自动算出总金额。
  导出的订单表格包含：订单号、日期时间、客户、规格、单价、数量、
  小计、订单总额、付款状态（不含产品、价格档两栏）。
- 「合并生成账单（勾选）」：在订单列表勾选几笔订单，点这个按钮就把它们
  合并成一张账单导出（Excel 表格 .xlsx），只导出、不改状态。
  勾的都是同一个客户的订单 = 一张账单；勾了多个客户 = 自动合并成一张。
  账单排版：按日期从早到晚排列，每天下面按客户分小节，每小节有一行表头
  （订单号/规格/单价(元)/数量/小计(元)），下面列每笔订单的完整明细；
  每个客户有小计、每天有合计，最后一行是 ★ 总合计 ★。
  金额显示整数（如 117，有小数才显示小数，如 10.5）。

【账单管理】
- 每下一单，订单会自动出现在「账单管理」里（状态 = 未完成）。
- 左侧是客户列表（显示每个客户的未开账单数量和金额），
  点客户名，右侧显示该客户的未完成订单（不显示下单日期，客户名不带批发/VIP 尾称）。
- 客户列表上方有「全选」勾选框：打勾 = 一次性勾上所有客户（配合下面的合并账单），
  取消 = 全部不勾。
- 订单列表上方也有「全选」勾选框：打勾 = 勾选该客户全部订单，取消 = 全部不勾。
- 勾选要开的订单 → 点「合并导出账单」，得到一张账单文件（Excel 表格 .xlsx）。
- 多客户合并：左侧每个客户名前都有勾选框，勾选 2 个及以上客户后，
  右侧会显示合并预览，点「合并导出账单」就把这些客户的所有未开账单订单
  合并成一张账单。只勾 1 个客户 = 和点他一样，单独查看他的订单。
- 账单排版（和订单管理里的合并账单一样）：按日期从早到晚排列，
  每天下面按客户分小节（每小节有一行表头：订单号/规格/单价(元)/数量/小计(元)），
  每个客户有小计、每天有合计，最后一行是 ★ 总合计 ★；
  金额显示整数（如 117，有小数才显示小数，如 10.5）。
- 导出后这些订单自动标记为「已完成」，并从账单管理里消失；
  订单管理里能看到它们已变成已完成。
- 历史订单默认都是未完成，可以补开账单。
- 导出文件名自动编号：同一天第一次导出叫「账单王二20261105」，
  再导出同名文件会自动变成「账单王二2026110501」「…02」…，
  保存时不用再手动改名字，直接点保存即可。
- 保存窗口会自动打开在你上次保存账单的文件夹（比如桌面），
  序号就在那个文件夹里数，不用管文件存在哪。

【统计】
- 点顶部「统计」，选日期范围（今天/本周/本月/上月/全部），
  汇总表按 产品-规格-入库数-销售数量-剩余数量-销售金额 排列：
  入库数 = 创建规格时填的初始库存 + 全部补货累计（不看日期范围；
  用「纠错」直接改库存的数字不算入库），
  销售数量/金额 = 所选日期范围内卖出的，
  剩余数量 = 当前实际剩余（缺货显示红色负数）；
  有初始库存的规格都会列出来（基本等于全部规格）。
  下方订单明细表是范围内的每一笔订单，表上方有搜索框，
  可搜订单号/客户/品名/规格，导出明细表也只导出搜索后的结果。
- 「客户收款汇总」表在销售汇总和订单明细之间，按客户统计所选日期范围内的：
  总下单金额、已支付金额、未支付金额（未支付红字），按总金额从高到低排列，
  最下面一行是合计；点标题旁的「导出客户收款表」可导出 Excel 表格。
  客户按订单上记录的客户名统计（客户删除了也能统计到），
  已支付金额 = 付款状态为已付款的订单金额。
- 可以导出汇总表和明细表（Excel 能打开），明细表末尾带总金额。
- 点「生成分析报告」，软件会根据当前库存和订单自动生成一份文字报告：
  整体概况、库存预警（缺货/低库存）、滞销积压、卖得好的产品、
  客户收款（全部历史的收款概况和未结清客户名单，行动建议里带催收提醒）、
  行动建议、生成时间；报告可以一键复制文字，也可以导出成 TXT、Excel，
  或「一页纸 PDF」：竖版 A4 单页排版，关键数字做成大号指标卡，
  缺货红字、低库存橙字、行动建议用高亮卡片，一眼就能看到重点，
  适合打印或直接发给别人看（清单项特别多时每节只列前 8 条，
  完整明细在 TXT/Excel 导出里有）。

【识别订单（微信截图 / 粘贴文字）】
方式一：截图识别
1. 客户在微信里发来文字订单（比如"螺丝 M6×30 10件，螺母 20个"）时，
   在电脑微信里把这段文字截个图。
2. 回到软件「新建」页，点订单栏里的「识别订单（截图/照片）」。
3. 按键盘 Ctrl+V 把截图粘贴进去（也可以点「选择图片」打开图片文件）。

方式二：粘贴文字（更快更准）
1. 在微信里选中客户发来的订单文字，按 Ctrl+C 复制。
2. 打开「识别订单」窗口，把文字粘贴到左下角的文本框里，
   点「识别粘贴的文字」即可，之后流程和截图识别一样。

后续步骤（两种方式相同）：
4. 软件会自动识别文字并试着对上产品。请务必逐行核对：
   - 识别对的保留，数量不对的直接改数字；
   - 识别错的多余行点「删除」；
   - 没对上的行点「对应产品」手动选；整行漏掉的点「＋ 补一行」补上。
   - 名字旁边多出字母的行（比如写了 vip10，可能被误看成 ip10），
     软件不会自动配错，会列成未匹配行，并在旁边给出「疑似」候选按钮，
     点一下就能对应上。
5. 核对完点「全部加入订单」，回订单栏照常选客户、填订单号、下单。
注意：问候语、客套话（"谢谢"）、聊天时间等无用的行会自动忽略，不会出现在审核列表里。
识别不保证 100% 准确，下单前一定要逐行核对！
手写的单子、太模糊的截图识别效果差，不适合用这个功能。
所有识别都在本机完成，图片不会发到网上。

【批量导入（Excel 模板）】
1. 「产品与客户」页点「批量导入」→「① 下载导入模板」，得到一个 Excel 表格。
2. 用 Excel 或 WPS 打开模板，照着示例行填写（示例行可删）：
   - 产品名、规格名：必填。表里有但软件里没有的会自动新建。
   - 批发价/VIP价/零售价：填数字（可带小数），留空 = 保持原价不动。
     新建规格至少要填一档价格。
   - 库存：填了数字 = 用表格里的数覆盖软件里的库存（可带一位小数）；留空 = 不动。
   - 已售数不会导入，不会被改动。
3. 填完保存，回到软件点「② 选择填好的表格导入」。
4. 软件会先显示预览（新增几个、更新几行、哪几行有问题会被跳过），确认后点「确认导入」。
5. 价格变动时：把新价格填进表格再导一次即可，新价覆盖旧价，
   已成交订单的价格不受影响。
6. 导入只新增和更新，不会删除软件里已有的产品。

【批量建客户 / 导出客户名单（产品与客户页）】
- 「批量建客户」：① 下载批量建客户模板，模板两列：客户名 | 客户类型；
  客户类型这一列在 Excel 里点一下单元格就有下拉框，直接选 批发/VIP/零售，不用打字。
  ② 填好后选择表格导入，预览确认后一次建好多个客户。
  客户名和软件里已有的重复会跳过并提示；类型没选或写错的行也会跳过。
- 「导出客户名」：把全部客户名导出成 Excel 表格（.xlsx），一列客户名。

【补货】
「补货」页有三块：
1. 手动补货：选产品规格 → 填本次进货数量（可带一位小数）→ 点「确认补货」，
   库存会在现有数字上累加。
2. 表格导入补货：点「① 下载补货模板」，模板三列：产品名 | 规格名 | 补货数量。
   填好后点「② 选择填好的表格导入」→ 预览确认 → 库存累加。
   产品/规格名要和软件里完全一致，对不上的行会跳过并提示。
3. 补货记录：手动补的和表格导入的都会自动记在这里；上面的搜索框里
   输入产品名或规格名，就能快速筛出某样东西的历次补货记录。
盘点后发现数字不对，想直接改成实际数字的，用「产品与客户」页里的「纠错」。

【最重要的：数据备份！】
- 所有数据都存在本文件夹里的「库存数据.json」文件中。
- 备份方法（任选其一，建议每周做一次）：
  1. 把整个「库存记录本」文件夹复制到 U 盘或发到微信收藏；
  2. 或在软件右上角点「导出备份」，把生成的备份文件保存好。
- 换电脑时：把整个文件夹拷到新电脑就能继续用；换浏览器不影响（这是软件，不是网页）。
- 注意：不要把文件夹放进 C:\Program Files 等系统目录（会存不了数据），
  放在桌面或 D 盘都可以。
